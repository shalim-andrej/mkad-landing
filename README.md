# «Москва за МКАД» — SEO-портал маршрутов выходного дня

Многостраничный контентный проект (лендинг + 4 SEO-страницы) для продвижения Telegram/MAX-канала о путешествиях по Подмосковью.

## Демо
🔗 [mkad.ucoz.net](https://mkad.ucoz.net/)

## Стек
- HTML5 / CSS3 (Grid, Flexbox, адаптив)
- JavaScript (интерактив, анимации)
- uCoz (CMS)
- Яндекс.Метрика (вебвизор, карта кликов)
- Schema.org (микроразметка Article, FAQPage, TouristTrip)
- Open Graph (для соцсетей)

## Что сделано:
- **Дизайн:** Премиум-дизайн в стиле туристического журнала (шрифты Manrope + Cormorant Garamond).
- **Структура:** Главная страница (хаб) и 4 посадочные страницы (Коломна, Сергиев Посад, Звенигород, Сенеж).
- **SEO-оптимизация:** Уникальные мета-теги (Title, Description), семантическая верстка, внутренняя перелинковка, микроразметка для попадания в расширенные сниппеты.
- **Аналитика:** Настроена Яндекс.Метрика (цели, вебвизор, карта скроллинга).
- **Конверсия:** Продуманы CTA-блоки (кнопки перехода в MAX) в каждом блоке страниц.
- **Контент:** Написан и сверстан экспертный контент (тайминги, бюджеты, гиды по городам).
