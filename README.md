# Лендинг для Telegram-канала «МКАД»

Одностраничный сайт для продвижения канала о путешествиях по Подмосковью.

## Демо
🔗 [mkad.ucoz.net](https://mkad.ucoz.net/)

## Стек
- HTML5
- CSS3
- JavaScript
- uCoz (платформа)

## Что сделано
- Дизайн и структура лендинга
- Конверсионная логика (от первого экрана до подписки)
- Адаптивная вёрстка под мобильные и десктоп
- Интеграция с Telegram
- Наполнение контентом
- Запуск в сеть
