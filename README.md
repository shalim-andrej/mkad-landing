# Лендинг «Москва за МКАД»

Премиум-лендинг для канала в Макс о путешествиях по Подмосковью. Готовые маршруты выходного дня без машины: цены, расписание, лайфхаки.

## Демо
🔗 [mkad.ucoz.net](https://mkad.ucoz.net/)

## Стек
- HTML5
- CSS3 (Grid, Flexbox, clamp())
- JavaScript (IntersectionObserver для анимаций)
- Google Fonts (Manrope + Cormorant Garamond)

## Что сделано
- Премиум-дизайн: крупная типографика, воздух, асимметрия
- Полноэкранный hero-блок с фото и оверлеем
- Блок статистики в стиле журнала
- Карточки маршрутов с номерами 01–04 (тёмный блок)
- Плавные анимации появления при скролле
- Полностью адаптивная вёрстка (desktop / tablet / mobile)
- Оптимизированные шрифты Manrope + Cormorant Garamond
